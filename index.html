Features

核心功能

少即是多：没有复杂的 App，没有唤醒词，一块屏、一个键，把大模型放到你手边。

🎙️

按住说话，开口即答

按下按键对着它说话，语音实时转写、大模型生成回答、清亮人声播报，全程不到一个呼吸的等待。

💬

看得见的对话

3.5 英寸触摸屏同步显示完整对话，中文渲染清晰细腻。听不清就低头看一眼，重要信息不划走。

🌙

勿扰模式

一键切换：深夜问它，只亮屏、不出声。屏幕亮度自动压暗，回答改成文字，不打扰枕边人。

🛠️

深度可定制

固件基于 Apache-2.0 授权的开源 SDK 深度定制，按键行为、提示词、外设皆可改——它是一块趁手的开发板。

Scenarios

应用场景

放在书桌、床头或工位上，谁都能用：不需要学习，开口就行。

WORK

桌面办公助手

  • 写着代码想查个问题，动口不动手
  • 天气、日程、汇率，抬手一问
  • 长文粘贴过来，让它念摘要
  • 中英互译，口语润色
COMPANION

日常陪伴

  • 睡前聊聊今天，讲个冷知识
  • 老人小孩零门槛，按住就能说话
  • 白噪音、番茄钟、正念呼吸
  • 夜里有它应一声，不孤单
MAKER

开发者乐园

  • ESP32-S3 + 触摸屏，标准 IDF 工程
  • 固件可定制，引脚定义文档齐全
  • 网关可自建，模型随便换
  • 接传感器、做桌宠、改 UI 都行
Hardware

硬件规格

当前开发者套件基于 Waveshare ESP32-S3-Touch-LCD-3.5 核心板，规格如下。

主控ESP32-S3 双核处理器，带 PSRAM
屏幕3.5 英寸 320×480 IPS 电容触摸屏
音频ES8311 编解码芯片，板载麦克风与扬声器
连接Wi-Fi 2.4GHz · USB-C 接口
电源USB-C 供电，预留锂电池接口（AXP2101 电源管理）
